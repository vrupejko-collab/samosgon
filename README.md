# 🥃 Самосгон 2.0 — Наследство

Сюжетный симулятор деревенского винокура: ноябрь, пустые карманы,
неисправный аппарат и бабушкина тетрадь с рецептами. Статические файлы,
работает в любом браузере и на GitHub Pages.

## Структура проекта

    samosgon.html        — движок и интерфейс
    data/materials.js    — материалы: семена, сахар, дрова, доски, гвозди, ремкомплект
    data/tools.js        — инструменты (ведро, ящик, чан, спиртометр, змеевик)
    data/recipes.js      — рецепты браги и записи тетради
    data/upgrades.js     — улучшения (аппарат, автополив, печь, лицензия)
    data/skills.js       — дерево саморазвития (3 ветви, 10 навыков)
    data/buildings.js    — уровни дома и сарая
    data/world.js        — покупатели, сезоны, погода, события
    img/                 — SVG-иллюстрации (архив samosgon-img.zip)

## Запуск

- **GitHub Pages:** Settings → Pages → ветка main.
- **Локально:** открыть samosgon.html в браузере.

## Сюжет и главы

1. Глава 1 «Наследство» — выживание: осмотреть сарай, брага, первые деньги.
2. Глава 2 «Первые деньги» — ремкомплект, расчистка сарая, первая перегонка.
3. Глава 3 «Хозяйство» — огород, сырьё, печь.
4. Глава 4 «Своё дело» — репутация, аппарат II, знак качества.
5. Глава 5 «Хозяин деревни» — аппарат III, лицензия.

## Выживание и мир

- Голод: растёт каждый день, быстрее в холоде. Еда — из магазина или с грядки.
- Усталость: сбрасывается сном; сон крепче в улучшенном доме.
- Дом и сарай: уровни из buildings.js — тепло, сон, лимиты грядок, чанов и аппарата.
- Сезоны: по 15 дней, старт с осени; зимой сажать нельзя, рост замедлен.
- Погода: ясность, дождь, ветер, непогода — влияет на температуру, жару и полив.
- Покупатели: Михалыч, перекуп на рынке, трактирщик «Кабачок» (world.js).
- События: обход участкового, путник, помощь соседа, холодный ветер в щели.

## Тетрадь бабушки

Записи открываются по мере игры и дают очки навыка. Секрет «Свекольной
старинной» лежит в сундуке — откроется при расчистке сарая (уровень 1).

## Балансировка

Все цифры лежат в файлах папки data. Если картинка не нашлась,
интерфейс автоматически подставляет эмодзи.
