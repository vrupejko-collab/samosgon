# 🥃 Samosgon: симулятор деревенского винокура

Симулятор жизни винокура в деревне Тыковка: наследство, грядки, брага,
перегонка, сбыт и вечный спор с участковым. Полностью автономный проект —
статические файлы, работает в любом браузере и на GitHub Pages.

## Структура проекта

    samosgon.html        — движок и интерфейс
    data/materials.js    — материалы для браги (сахар, семена, дрожжи, удобрения)
    data/tools.js        — инструменты (ведро, бутылки, чан, спиртометр, змеевик)
    data/recipes.js      — рецепты браги и страницы Вики винокура
    data/upgrades.js     — улучшения (автополив, склад, аппарат, лицензия)
    data/skills.js       — дерево саморазвития (3 ветви, 10 навыков)
    img/                 — SVG-иллюстрации по подпапкам:
      img/crops/         — свёкла, картофель
      img/materials/     — семена, сахар, дрожжи, удобрение, бутылка
      img/tools/         — ведро, ящик, чан, спиртометр, змеевик
      img/upgrades/      — автополив, аппараты I–III, второй этаж, знак качества, лицензия
      img/wiki/          — баннеры страниц Вики
      img/recipes/       — банки с брагой

## Запуск

- **GitHub Pages:** Settings → Pages → ветка main → ссылка вида
  https://<логин>.github.io/samosgon/
- **Локально:** открыть samosgon.html в браузере.

## Механики

- Рецепты покупаются в магазине; изначально известна только бабушкина «Сахарная классика».
- Вики винокура открывается по мере игры: покупки, перегонки, вехи репутации.
- Каждая открытая страница Вики и каждая веха репутации дают очко навыка.
- Дерево саморазвития: ветви «Хозяин», «Мастер», «Купец» — всего 10 навыков.

## Балансировка

Все цифры — цены, урожайность, качество, сроки — лежат в файлах папки data.
Правишь данные — движок трогать не нужно. Если картинка не нашлась,
интерфейс автоматически подставляет эмодзи.
